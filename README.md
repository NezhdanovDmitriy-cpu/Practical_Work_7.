# Практическое занятие № 7 — Вариант 11

Тема: Составление программ со строками в IDE PyCharm Community.

- `analysis.py` — анализ программы со случайными символами и переводом букв в нижний регистр.
- `task_1.py` — вставка одного пробела между символами непустой строки.
- `task_2.py` — выделение первого каталога из полного пути Windows; для файла в корне выводится `\`.

Запуск: открыть проект в PyCharm Community, выбрать нужный `.py`-файл и нажать Run.

Примеры:
- `Python` → `P y t h o n`
- `C:\Students\Python\file.txt` → `Students`
- `C:\file.txt` → `\`
